# Данные Titanic

Источник — [OpenML Titanic №40945, версия 1](https://www.openml.org/d/40945).
В карточке OpenML лицензия указана как `Public`. Стадия `get_data`
скачивает исходник без токена и проверяет SHA-256.

| Файл | Содержимое |
|---|---|
| `raw/titanic.arff` | Исходный набор из 1 309 пассажиров |
| `prepared/titanic.csv` | Признаки для обучения и целевая переменная |

| Колонка | Значение |
|---|---|
| `age` | Возраст в годах |
| `fare` | Стоимость билета |
| `sibsp` | Число братьев, сестёр и супругов на борту |
| `parch` | Число родителей и детей на борту |
| `pclass` | Класс билета |
| `sex` | Пол пассажира |
| `survived` | Целевая переменная. `1` — выжил, `0` — погиб |

Пропуски в возрасте и тарифе сохраняются. При обучении медиана для
заполнения пропусков вычисляется только на обучающей выборке.

Тег `data-v1` фиксирует подготовленный CSV со всеми 1 309 пассажирами.
